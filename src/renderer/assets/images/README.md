# 画像素材

イラストやアイコン画像（webp / png / svg）はこのフォルダに置き、`import url from './xxx.webp'` で読み込む。

学生に配布するアプリなので、素材を追加したら必ず下の表に出典とライセンスを書くこと。
「Web で拾った画像」はライセンス不明のまま配布すると問題になるため、利用規約を確認できるものだけを使う。

| ファイル | 出典 URL | ライセンス / 利用条件 | クレジット表記 |
|---|---|---|---|
| （例）mascot.webp | https://example.com/... | 商用・教育利用可、改変可 | 不要 |
